# Dynamic Campus Website

A complete React-based campus website with responsive sections for academics, admissions, faculty, events, student life, gallery, contact, and portal access.

## Tech Stack

- React + Vite
- Modern CSS (responsive, accessible layout)
- Local mock content architecture using reusable data objects/arrays

## Run Locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually `http://localhost:5173`).

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm run preview` - Preview production build
- `npm run lint` - Run project linter

## Features Included

- Responsive homepage with hero, stats, highlights, and CTA buttons
- About section with mission, vision, values, history, and campus highlights
- Searchable/filterable departments and program cards
- Faculty and staff directory cards
- Admissions process, requirements, deadlines, and support CTA
- Filterable events and announcements section
- Student life content for clubs, facilities, and housing/transport
- Campus gallery with remote image cards
- Contact details, office hours, map placeholder, and validated contact form UI
- Student and faculty portal access cards
- Reusable data-driven architecture to support future API/CMS integration
